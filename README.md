# VK Case Champ · Бишка

Локальная демоверсия бизнес-сообщества ВКонтакте. Обложка, аватар и иллюстрация услуги взяты из предоставленных референсов. Белые карточки, VK Sans Display и фирменный синий опираются на [брендбук VK](https://corp.vkcdn.ru/media/files/rukovodstvo-po-vizualnomu-stilyu.pdf).

## Запуск

Откройте папку проекта в VS Code и выполните команду npm run dev. Нужен Node.js 22 или новее. Рабочий адрес http://127.0.0.1:5173. Команда npm run build собирает статические файлы в dist/.

## Маршруты для показа

- **Запуск магазина.** Мой бизнес → Обзор → выбрать способ продаж. В «Товарах» открыть «Проверить готовность», затем пробное оформление. Оно не создаёт заказ и не увеличивает воронку.
- **Продажа из клипа.** В Chrome открыть http://127.0.0.1:5173/#clips/1 и нажать на плашку товара в ролике и выбрать «Купить ВКонтакте». Выбрать доставку или самовывоз и ввести BISHKA10. После тестовой оплаты найти заказ у продавца и в статистике VK Клипов.
- **Первые показы.** В проверке готового товара нажать «Показать первым покупателям». Открыть выдачу Маркета и вернуться к статистике, чтобы увидеть показ.
- **Подарок.** На карточке товара нажать «Подарить» и завершить тестовую оплату. В сообщениях по заказу открыть подарок от лица получателя, выбрать вариант и ввести вымышленный адрес.
- **Переписка.** На странице сообщества нажать «Написать магазину». Со стороны покупателя диалог открывается в «Мессенджер → Покупки». Ответить можно в «Мой бизнес → Переписки». У заказа есть своя переписка. Личные диалоги находятся в одноимённой вкладке Мессенджера.
- **Управление.** В «Мой бизнес → Продвижение» создать пост с товаром ; вопросы по товарам находятся в «Общение → Вопросы покупателей». Видимость разделов настраивается в «Мой бизнес → Настройки → Сообщество».
- **Корзина.** Добавить товары ВКонтакте и Ozon из общей выдачи Маркета. Для товара с двумя способами покупки площадку можно выбрать в корзине. Оформление ВКонтакте сохраняет позиции Ozon в корзине.
- **Доставка.** После тестовой оплаты открыть заказ у продавца и изменить статус. В «Мессенджер → Уведомления о доставке» покупатель увидит обновление и ссылку на заказ.
- **Обучение.** В разделе «Сообщества» открыть новое сообщество. Пройти 11 шагов от оформления витрины до проверки источника заказа или обращения. В «Запуске магазина» есть кнопка «Сбросить демо» для повторного показа.

Данные хранятся в браузере. Платежи, подарки, публикации, переписка, показы и рекламные черновики работают локально. Для защиты добавлен восьмисекундный вертикальный MP4 с анимацией фотографии пончо. Остальные клипы без источника видео показываются с пустым плеером. Поиск по бюджету и сроку и подсказка категории используют правила. Ссылка на Ozon задаётся в карточке товара; формат ручного импорта описан ниже. Прочие инструменты ВКонтакте собраны в «Управление → Другие инструменты» как справочный список.


## Обновление единого покупательского сценария

Карточки открываются по `#product/ID` в новой вкладке: фото/видео, описание, характеристики, ожидаемая дата, покупка, вопросы, отзывы, переход в сообщество, похожие товары и «С этим покупают». В каталоге четыре демомагазина, боковые фильтры и сердечко. Дополнительные товары иллюстрированы SVG; продавец может загрузить фотографию.

- VK Pay: отдельный пункт меню, демобаланс, тестовая карта (только последние 4 цифры), способ по умолчанию, операции и возвраты. Реального эквайринга нет.
- Карточки → «Вопросы покупателей» → правила помощника. Ответы видны в карточках. Сообщения остаются для консультаций; оформление в сообщениях исключено.
- Поддержка: видимая кнопка на всех экранах и контекстная ссылка из заказа. Бот использует сценарии, неизвестный вопрос сохраняет как заявку оператору. Реальная служба поддержки не подключена.
- Отзыв после получения: звёзды одним нажатием в заказе, чате и уведомлениях, необязательный текст/медиа. Заказ завершается независимо от оценки. Напоминание сохраняется до оценки.
- Подписка на поступление: уведомление при изменении остатка продавцом или импорте. Уведомления браузера работают с разрешения пользователя при открытом сайте. Фоновые Web Push требуют серверного провайдера и service worker.
- Подарок: список демодрузей или ссылка VK, оплата, карточка в демочате, распаковка, вариант и адрес получателя. Сообщения не отправляются в настоящий VK.
- Импорт каталога: JSON из «Настройки → Интеграции», атомарная проверка цены/остатка/доставки/отзывов и источника. Это ручной импорт; автоматическое чтение Ozon/сайта по ссылке требует API/серверной интеграции. Внешние отзывы не выдуманы и не подмешаны как подтверждённые VK-покупки.
- Умное заполнение: правила извлекают название, категорию, цену, остаток и характеристики из текста. Обложка собирается в canvas из загруженного фото. Это локальный шаблон, без генеративной модели или удаления фона.
- Несколько сообществ в корзине: отдельный заказ и доставка для каждого; создание проверяется атомарно, чтобы ошибка второго магазина не списала остаток первого.

Данные и тестовые операции доступны только в этом браузере. Для продакшена нужны сервер, авторизация, эквайринг, поставщик уведомлений и API продавцов.
